## Description
```
Zera Desktop is a powerful desktop application for managing and transferring Zera private cash vouchers using NFC technology. Built for Windows x64 systems, this application enables secure, offline transfer of digital cash vouchers to and from NTAG216 NFC tags.

**Key Features:**

• **NFC Tag Support** - Read and write vouchers to NTAG216 NFC tags
• **Drag & Drop Interface** - Intuitive workflow for organizing and transferring vouchers
• **Multiple Reader Support** - Works with ACR122U and other PC/SC-compatible NFC readers
• **Secure Storage** - Private voucher data stored locally on your device
• **Fast Operations** - Optimized read/write operations for efficient transfers
• **Voucher Management** - View detailed information and manage your voucher collection

**System Requirements:**

• Windows 10 or later (64-bit)
• Compatible NFC reader (ACR122U recommended)
• NTAG216 NFC tags

**Getting Started:**

1. Download and run the installer
2. Connect your NFC reader to your Windows PC
3. Launch Zera Desktop
4. Drag vouchers to the write zone to transfer them to NFC tags
5. Use the read function to retrieve vouchers from tags

Perfect for scenarios where you need to transfer value offline or manage private cash vouchers without an internet connection.

**Note:** Windows Defender may show a warning when installing unsigned applications. This is normal for applications without code signing certificates. The application is safe to use.
```
